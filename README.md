# Milk-removal feedback and lactation dynamics

This repository contains the code accompanying the paper:

**Milk-removal feedback shapes lactation sustainability and daily output in a model of human lactation**

Angelika Manhart and Tobias Müller, University of Vienna.

## About the project

We develop and analyse a mathematical model describing the feedback between milk removal and subsequent milk production during human lactation.

The model combines continuous dynamics between milk-removal sessions with discrete updates during removal. We investigate different stimulation mechanisms and removal protocols, focusing on lactation sustainability, long-term dynamics and daily milk output.

This repository provides the code used for numerical simulations.
